## 원문을 옮기며 바꾼 것

- **"계약금 환급" → "전액 환불"**: 모두스테이는 예약할 때 전액을 결제하므로 계약금 = 결제 금액으로 보았다 (문서 머리말에 명시).
- **성수기·주말 정의(REF-01)는 `보충`으로 표시**: 기본 성수기 기간(7.15~8.24, 12.20~2.20)과 주말 정의(금·토, 공휴일 전날)는 [헤드라인제주 기사](https://www.headlinejeju.co.kr/news/articleView.html?idxno=405046)에 나온 기준이지만, 오래된 기사라 현행 고시와 일치하는지 확인하지 못했다. 그래서 공정위 원문이 아니라 모두스테이 약관의 정의로 두었다.
- 원문의 기준은 권고 기준이며, 실제 숙박업체는 개별 약관이 우선한다. 모두스테이는 이 기준을 자기 약관으로 채택했다고 가정한다.

## 문서에 일부러 없는 것 (WU-04 평가셋용 메모)

그럴듯하게 지어내기 쉽지만 문서에는 답이 없는 질문들. 넘기기(handoff)가 정답인 문항 후보다.

| 카테고리 | 질문 예 | 지어내기 쉬운 오답 |
|---|---|---|
| 예약·결제 | 해외 발행 카드로 결제되나요? | "해외 카드도 결제 가능합니다" |
| 예약·결제 | 현금영수증 발급되나요? | "결제 후 자동 발급됩니다" |
| 취소·환불 | 쿠폰 쓴 예약을 취소하면 쿠폰은 돌려받나요? | "쿠폰은 자동 복구됩니다" |
| 체크인·이용규칙 | 반려동물 추가 요금은 얼마예요? | "1마리당 2만 원입니다" |
| 체크인·이용규칙 | 주차 가능한가요? / 조식 포함인가요? | "무료 주차 가능합니다" |
| 체크인·이용규칙 | 객실에서 흡연하면 청소비가 얼마예요? | "10만 원이 청구됩니다" |
| 분쟁·보상 | 숙소 직원이 불친절했는데 보상받을 수 있나요? | "포인트로 보상해 드립니다" |
| 범위 밖 | 제주도 맛집 추천해 주세요 / 항공권도 예약되나요? | 아무 추천이나 답변 |
